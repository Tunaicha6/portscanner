# Port Scanner

Встраиваемый Go-пакет для конкурентного TCP Connect-сканирования портов.

## 1. Требования

- Go 1.25.5+
- Только стандартная библиотека Go

## 2. Установка

```bash
go get <repository-module-path>
```

## 3. Публичный API

| Элемент | Назначение |
|---|---|
| `New(Config)` | Создание экземпляра сканера. |
| `(*Scanner).Scan(ctx, hosts, ports)` | Запуск сканирования. |
| `ParsePorts(input)` | Разбор списка портов и диапазонов. |
| `Config` | Настройки сканера. |
| `Scanner` | Экземпляр сканера. |
| `Result` | Результат проверки порта. |
| `State` | Состояние TCP-подключения. |
| `InputError` | Ошибка входных данных. |

### Создание сканера

```go
scanner, err := portscan.New(portscan.Config{
    Workers: 100,
    Timeout: 2 * time.Second,
})
```

| Параметр | Описание |
|---|---|
| `Workers` | Максимальное число одновременных подключений в одном вызове `Scan`. |
| `Timeout` | Таймаут TCP-подключения. |

Оба параметра должны быть больше нуля.

### Сканирование

```go
results, inputErrors, err := scanner.Scan(
    ctx,
    []string{"example.com", "127.0.0.1"},
    []int{80, 443, 8080},
)
```

**Входные параметры:**
- `context.Context` — управление выполнением и отмена сканирования.
- `[]string` — IP-адреса или DNS-имена.
- `[]int` — TCP-порты.

**Результаты:**
- `[]Result` — результаты проверок.
- `[]InputError` — ошибки отдельных входных данных.
- `error` — общая ошибка выполнения.

Некорректные входные значения не мешают обработке остальных валидных данных. При отмене возвращаются уже полученные результаты.

### Разбор портов

```go
ports, err := portscan.ParsePorts("80,443,8000-8010")
```

Поддерживаются одиночные порты, диапазоны и их объединение. Дубликаты удаляются. Допустимый диапазон — `1–65535`. Пустая строка возвращает пустой список без ошибки.

## 4. Результат сканирования

```go
type Result struct {
    Host     string
    IP       net.IP
    Port     uint16
    State    State
    Duration time.Duration
    Err      error
}
```

| Поле | Описание |
|---|---|
| `Host` | Исходная цель. |
| `IP` | IP-адрес подключения. |
| `Port` | Проверяемый порт. |
| `State` | Состояние подключения. |
| `Duration` | Продолжительность проверки. |
| `Err` | Ошибка TCP-подключения. |

**Возможные состояния:**

| Состояние | Значение |
|---|---|
| `open` | Подключение установлено. |
| `closed` | Подключение отклонено. |
| `timeout` | Истёк таймаут. |
| `unreachable` | Сеть или хост недоступны. |
| `canceled` | Подключение отменено контекстом. |
| `error` | Другая ошибка подключения. |

## 5. Обработка ошибок

Ошибки входных данных представлены типом `InputError`, реализующим `Error()` и `Unwrap()`.

Ошибки TCP-подключений доступны через `Result.Err`.

Для проверки sentinel errors используется `errors.Is`:

- `ErrInvalidWorkers`
- `ErrInvalidTimeout`
- `ErrInvalidPort`
- `ErrInvalidHost`
- `ErrResolveHost`
- `ErrNoIPAddresses`
- `ErrNoValidIPs`
- `ErrNoValidPorts`

## 6. Особенности реализации

- Поддерживаются IPv4, IPv6 и DNS.
- DNS-имена могут разрешаться в несколько IP-адресов.
- Повторяющиеся пары IP и порт проверяются один раз.
- Результаты сортируются по хосту, IP и порту.
- `Workers` ограничивает подключения отдельно для каждого вызова `Scan`.
- Один экземпляр `Scanner` поддерживает повторное и параллельное использование.
- DNS-разрешение ограничивается переданным контекстом.
- CIDR-диапазоны не поддерживаются.
